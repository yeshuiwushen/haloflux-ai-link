HALOFLUX - Wallpaper Engine 安装说明 / Installation
=====================================================

【中文】安装
1. 打开 Steam 库，右键 Wallpaper Engine → 管理 → 浏览本地文件。
2. 依次进入 projects → myprojects 文件夹（没有 myprojects 就新建一个）。
3. 把整个 HALOFLUX 文件夹放进去，最终路径应为：
   ...\wallpaper_engine\projects\myprojects\HALOFLUX\project.json
   （注意不要多套一层文件夹）
4. 完全退出 Wallpaper Engine（右下角托盘图标右键 → 退出），再重新打开。
5. 在「已安装」列表里找到 HALOFLUX，点击即可应用。
   右侧面板可调：视觉预设、节拍速度、圆环转速、自动运镜、柔光、光束辉光、
   扫描线、界面面板开关、背景音乐与音量。
   找不到时，检查左上角「筛选结果」是否把它过滤掉了。
6. 想自己修改：打开 Wallpaper Engine 编辑器 → 打开壁纸 → 从文件打开 →
   选择 HALOFLUX\project.json。

【English】Install
1. In your Steam Library, right-click Wallpaper Engine -> Manage -> Browse local files.
2. Open projects -> myprojects (create "myprojects" if it does not exist).
3. Put the whole HALOFLUX folder inside, so the path is:
   ...\wallpaper_engine\projects\myprojects\HALOFLUX\project.json
4. Fully quit Wallpaper Engine (tray icon -> Quit) and start it again.
5. Find HALOFLUX in the Installed list and click it to apply.
6. To edit it: Wallpaper Engine editor -> Open Wallpaper -> Open from file ->
   pick HALOFLUX\project.json.
